# Week 3 - Simple AI Recommendation System

## About

This project is a simple recommendation system built using Python. It recommends courses based on the user's interests. The program compares the interests entered by the user with predefined keywords and suggests the courses with the highest matches.

The main purpose of this project is to understand the basic idea behind recommendation systems using simple Python logic.

## Features

- Takes user interests as input
- Matches interests with course keywords
- Recommends the most relevant courses
- Displays a match score for each recommendation
- Handles cases where no matching course is found

## Technologies Used

- Python

## How It Works

1. The user enters their interests separated by commas.
2. The program compares those interests with the keywords assigned to each course.
3. A match score is calculated.
4. Courses are displayed in descending order of their match score.
